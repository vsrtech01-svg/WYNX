# German Cakes — Official Website

Premium bakery website for German Cakes, Bindayaka, Jaipur. Built with React + Vite + TypeScript, backed by Firebase (Auth, Firestore, Storage).

## Getting Started

```bash
npm install
npm run dev
```

## Environment Variables

Copy `.env.example` to `.env` and fill in your Firebase project credentials.

## Deployment

See `.env.example` for required variables. Deploy to Vercel or Netlify with `npm run build`.
